# Theme Tokens

All styling values in Nebula ERP derive from `src/core/ui/theme/tokens.ts`.

## Token Categories
- **spacing**: `xs` (4px), `sm` (8px), `md` (16px), `lg` (24px), `xl` (32px), `xxl` (48px)
- **radius**: `sm` (8px), `md` (12px), `lg` (16px), `full` (9999px)
- **shadow**: `xs`, `sm`, `md`, `lg`
- **colors**: `primary`, `secondary`, `success`, `warning`, `danger`, `surface`, `background`, `text`, `border`
- **typography**: `fontFamily`, `heading`, `subheading`, `body`, `caption`
- **transitions**: Standardized cubic-bezier transitions
- **breakpoints**: `sm`, `md`, `lg`, `xl`
- **zIndex**: Layering scale from `dropdown` to `tooltip`
